# 충북 지도 소개 영상 제작 안내

저장소 루트의 AGENTS.md에 따라 작업한다. 먼저 [영상 구성안](README.md)과 [디자인 체크리스트](../CHECKLIST.md)를 읽는다. 사진은 public/screens/에 있다.

첫 장면은 “우리 지역에는 어떤 학교가 있고, 어디에 있을까요?”로 시작한다. 충북 학생·학부모·교직원이 지역의 학교 정보를 쉽게 찾아보도록 만들었다는 목적과 세 단계(인구 보기 → 학교 분포 보기 → 관심 학교 고르기)를 소개한다. 이어서 시나리오 순서대로 인구밀도 지도, 지역 선택, 단양 읍·면, 제천 행정동, 하트, 찜 카드 위치, 찜 목록을 보여 준다. 비교 화면의 확대 범위를 좌우로 맞추고, 사용자의 실제 요청을 인용할 때는 구성안의 원문을 사용한다. 바꾼 이유는 별도의 자막으로 표시한다.

## 제작 및 확인

새 환경에서는 다음 명령으로 저장소에 고정된 버전을 설치한다. 저장소 루트에서 시작한다.

```sh
cd video
npm ci
npx remotion browser ensure
```

제작 요청을 받으면 src/index.jsx에 Remotion 진입점을 만들고 ChungbukIntro라는 컴포지션을 등록한다. 가로 1920×1080, 30fps, 5340프레임(2분 58초)을 기준으로 한다. 아래 명령은 video 폴더에서 실행한다.

```sh
npm run studio -- src/index.jsx
# 미리보기 확인 후 별도 터미널에서 실행
npm run render -- src/index.jsx ChungbukIntro out/chungbuk-intro.mp4 --codec=h264
```

완성본의 재생 시간과 첫 장면·일곱 비교 장면·마지막 장면을 확인한다. 작은 화면에서도 하트, 동 이름, 한글 자막이 읽히는지 점검한다. 소스는 한국어 커밋으로 main에 반영한다. out/은 Git에서 제외되어 있으므로 MP4는 사용자가 접근할 수 있는 첨부 파일 또는 다운로드 링크로 별도 전달한다. 결과와 함께 지도 앱 링크도 제공한다.
